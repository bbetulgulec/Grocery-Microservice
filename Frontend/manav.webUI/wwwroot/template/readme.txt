# GreenHarvest — Free Organic Farm & Food Website Template

GreenHarvest is a clean, modern, ready-to-use, single-page HTML website template created for organic farms, fresh produce and grocery brands, farm-to-table businesses, organic food stores, agriculture and agribusiness startups, dairy and eco-food producers, farmers' markets, gardening services, healthy-food delivery businesses, and other nature-focused food and agriculture brands.

Built with Bootstrap 5.3, HTML5, CSS3, and lightweight vanilla JavaScript, GreenHarvest combines a warm, natural visual style with modern interactive features. It includes built-in light and dark modes, a cross-fading hero slideshow, sticky menu presentation, background video, image and video lightboxes, testimonials, scroll animations, scrollspy navigation, and a fully responsive layout.

## How to Edit the Template

### 1. Edit Website Text

Open:

```text
index.html
```

in a code editor such as Visual Studio Code.

You can edit:

- Hero headline and supporting text
- Product category names
- Process steps
- Menu items
- About content
- Featured product information
- Statistics
- Certification content
- Testimonials
- Blog/article information
- Newsletter content
- Contact information
- Button labels
- Footer information

Search for the visible text you want to change and replace it directly.

---

### 2. Replace Images

Add your own images to:

```text
assets/img/
```

Then update the corresponding image paths inside `index.html`.

Example:

```html
<img src="assets/img/your-organic-farm-image.jpg"
     alt="Fresh organic produce from our farm">
```

For the best results:

- Use high-quality photographs
- Optimize large images before uploading
- Use descriptive filenames
- Add meaningful `alt` text
- Keep image dimensions appropriate for their sections

---

### 3. Update Brand Name and Logo

Open `index.html` and locate the navigation/logo area.

Replace the GreenHarvest brand name or existing logo with your own business identity.

If using an image logo, place it inside:

```text
assets/img/
```

Example:

```html
<img src="assets/img/logo.png" alt="Your Organic Farm">
```

---

### 4. Edit Colors

GreenHarvest is designed around a natural organic-food visual direction.

The main color system is controlled through CSS variables, making it easy to rebrand the entire website.

Open:

```text
assets/css/main.css
```

Locate the CSS variables near the beginning of the stylesheet and update the relevant color values.

Depending on the packaged version, variable names may include values for:

```css
--primary
--secondary
--background
--surface
--text
--heading
--border
```

Keep sufficient contrast between backgrounds, body text, headings, navigation elements, and call-to-action buttons.

Remember to review your changes in both Light and Dark modes.

---

### 5. Customize Light & Dark Mode

GreenHarvest includes built-in light and dark themes.

Visitors can switch themes using the navbar toggle. Their selected preference is remembered for future visits.

When customizing the design, test:

- Main backgrounds
- Alternate section backgrounds
- Cards
- Headings
- Paragraph text
- Borders
- Buttons
- Navigation
- Footer
- Gallery overlays
- Form elements

in both themes to maintain good readability and contrast.

---

### 6. Replace the Background Video

The template includes an auto-playing, muted background-video highlight band.

Replace the sample video source in `index.html` with your own optimized web video.

For best performance:

- Use an optimized MP4/WebM video
- Keep the file size reasonable
- Avoid excessively long clips
- Keep autoplay video muted
- Use an appropriate poster image when needed

---

### 7. Replace the YouTube Video

The video banner uses a public YouTube video as demonstration content.

Find the existing YouTube/video lightbox URL in `index.html` and replace it with your own YouTube video URL.

The video opens inside the GLightbox popup without requiring visitors to leave the page.

---

### 8. Edit Contact and Newsletter Information

Locate the newsletter/contact call-to-action section and footer in `index.html`.

Update:

- Email address
- Phone number
- Business address
- Social links
- Newsletter copy
- CTA labels
- Footer details

Important: If the template includes a static form, server-side submission processing is not included by default. Connect the form to your preferred backend, email service, API, or third-party form provider if you need to receive submissions.
